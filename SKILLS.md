# Engineering Skills & Competencies Required

Dokumen ini memetakan keahlian teknis yang dibutuhkan oleh tim pengembang atau agen AI dalam membangun dan memelihara sistem ini:

## 1. Backend & Architecture Skills
- **Hexagonal Architecture Mastery**: Kemampuan memisahkan domain business logic dari framework luar menggunakan port, adapter, use cases, dan entity murni.
- **Next.js 16+ App Router**: Pengelolaan Server Components, Route Handlers, dan Server Actions secara efisien.
- **Prisma v7 ORM**: Penulisan migrasi skema database relasional, relational mapping, dan query optimization dengan PostgreSQL.

## 2. Testing & Quality Assurance
- **Test-Driven Development (TDD)**: Disiplin menulis unit test sebelum implementasi kode produksi.
- **Triple A Pattern (Arrange-Act-Assert)**: Struktur penulisan unit test yang bersih, prediktif, dan mudah dibaca.
- **Jest / Vitest**: Eksekusi pengujian mocking repositori dan assertion asinkron.

## 3. Frontend & UI/UX
- **Tailwind CSS v4.3**: Penerapan utility-first styling, responsive grid layouts, dan kustomisasi palet warna modern (Slate, Emerald, Orange).
- **TypeScript Advanced Types**: Strict type checking, interface contracts, dan DTO mapping untuk integritas data end-to-end.
